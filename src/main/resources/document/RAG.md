# Spring AI RAG 基础概念

## 什么是 RAG

RAG（Retrieval-Augmented Generation，检索增强生成）是一种将外部知识检索与大语言模型生成相结合的技术架构。它的核心思想是：在模型回答用户问题之前，先从知识库中检索出与问题相关的文档片段，将这些片段作为上下文一并送入模型，从而让模型的回答基于真实、可控的知识来源，而不是仅依赖训练时记忆的参数。

## RAG 的工作流程

一个典型的 RAG 流程包含三个主要阶段：

1.  **索引阶段**：将原始文档切分为较小的片段（chunk），通过 Embedding 模型把每个片段转换为向量，存入向量数据库。
2.  **检索阶段**：用户提问时，将问题也用同一个 Embedding 模型转换为向量，在向量数据库中做相似度搜索，召回最相关的若干片段。
3.  **生成阶段**：把召回的片段与用户问题一起组装成提示词，交给大语言模型生成最终回答。

## Spring AI 中的关键组件

Spring AI 为 RAG 提供了完整的抽象：

- **Document**：表示一段文档内容及其元数据。
- **DocumentReader**：负责从各类数据源读取文档，例如 Markdown、PDF、JSON。
- **EmbeddingModel**：将文本转换为向量表示。
- **VectorStore**：向量存储与相似度检索的抽象，SimpleVectorStore 是内存实现。
- **QuestionAnswerAdvisor**：将检索结果自动注入对话上下文的 Advisor。

## 适用场景

RAG 适合知识频繁更新、需要引用来源、或模型训练数据未覆盖的领域，例如企业内部文档问答、产品手册查询、法规政策检索等。
